## Token Flow Summary

| Layer | Source | Output |
|---|---|---|
| **Primitives** | `tokens/global.json` | `--global-color-*`, `--global-font-*`, `--global-spacing-*` |
| **Component** | `design-system/component.json` | `--component-button-*`, `--component-card-*`, etc. |
| **Theme** | `src/index.css` | `:root` / `.light` / `.dark` semantic aliases |
| **Module** | `*.module.css` | Scoped styles consuming `var(--…)` tokens |

## Component Consumption

```
src/shared/ui/*        → Implementation (TSX + CSS Module)
src/components/*       → Re-export barrel for app/story imports
src/components/search-hub/* → Feature-level composites
src/pages/*            → Route-level pages
```
